Wallpaper presets
=================
Any image or video placed in this folder shows up in Settings > Background > Wallpapers.

Supported: PNG, JPG, WebP, GIF, AVIF, MP4 (H.264), WebM.
The file name becomes the preset name:  "Slow-Nebula.mp4"  ->  "Slow Nebula".

Tips
- 1920x1080 is plenty. Larger images only cost memory.
- Videos should loop seamlessly, be muted or silent, and stay under ~10 MB.
  Resolution 1280x720 at 24-30 fps is a good balance.
- Files in this folder ship with the launcher. For personal wallpapers use
  Settings > Background > Wallpapers > "Open my wallpapers folder" so they survive updates.
